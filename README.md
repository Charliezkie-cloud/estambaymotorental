# Estambay Moto Rental
An all-in-one web app for motorcycle rentals that gives admins total control over bookings, vehicle management, and daily operations.

# [Live Website](https://estambaymotorental.vercel.app/)

# Project Information
- Framework: Next.js v16

# Development
- Clone the project ``git clone https://github.com/Charliezkie-cloud/estambaymotorental.git``
- Install the npm packages/dependencies ``npm install``
- Setup the environment variables for emailing and supabase database. Refer to `.env.example` for the required environment variables
- Run the dev project `npm run dev`
